# Обработка персональных данных (152-ФЗ)

Это техническое описание, а не юридическая консультация. Тексты согласия и политики перед запуском должен проверить юрист.

## Принцип: не собирать то, что не нужно

| Этап | Что обрабатывается | Сохраняется ли |
|---|---|---|
| Тест и результат | ответы в памяти процесса | нет; увеличивается только обезличенный счётчик |
| Выдача практики | Telegram ID текущего чата (чтобы ответить) | нет |
| Подписка (после двух согласий) | ID, имя и @логин из Telegram, результат теста | да |
| Телефон (если `COLLECT_PHONE=true`) | номер, переданный кнопкой Telegram | да, только собственный номер пользователя |

Практика приходит прямо в чат, поэтому для её доставки контакт не нужен. В ТЗ так и сказано: контакт запрашивать, только если он действительно нужен для доставки.

## Как бот получает согласие

1. **Согласие на рассылку** — кнопка «Да, присылайте» (ст. 18 ФЗ «О рекламе»: реклама по сетям электросвязи требует предварительного согласия).
2. **Согласие на обработку ПДн** — отдельное сообщение с отдельной кнопкой «Даю согласие на обработку данных». С 01.09.2025 такое согласие должно оформляться отдельно от других документов. Полный текст открывается кнопкой; данные, цели, срок и способ отзыва показаны до нажатия.
3. Профиль сохраняется только после обоих шагов. Отказ на любом шаге — ничего не сохраняется.
4. Для доказательства согласия (ч. 3 ст. 9) хранятся `consented_at`, `consent_version` и `consent_method`.

## Права пользователя

| Право | Реализация |
|---|---|
| Узнать, какие данные хранятся (ст. 14) | `/mydata` |
| Отозвать согласие, удалить данные (ст. 21) | `/forget` — удаление сразу |
| Отписаться от рассылки | `/forget`; ссылка в каждой рассылке |
| Ознакомиться с условиями | `/privacy`, кнопка на приветствии |

## Хранение и защита

- Срок хранения: `DATA_RETENTION_DAYS` (по умолчанию 365 дней) с последнего обновления, затем автоудаление.
- Файл `data/users.json` хранится с правами `0600` и не попадает в git (`.gitignore`).
- Данные из групповых чатов бот не принимает, работает только в личных сообщениях.

## Что должен сделать оператор (вне кода)

1. **Подать уведомление в Роскомнадзор** об обработке ПДн (ст. 22) через pd.rkn.gov.ru — до начала обработки.
2. **Опубликовать политику обработки ПДн** (ч. 2 ст. 18.1) и указать ссылку в `POLICY_URL`.
3. **Заполнить реквизиты** в `.env`: `OPERATOR_NAME` (ФИО/наименование, ИНН или ОГРНИП) и `OPERATOR_CONTACT`.
4. **Разместить сервер с базой в России** (ч. 5 ст. 18 — локализация данных граждан РФ). Зарубежный VPS для хранения `users.json` не подходит.
5. Назначить ответственного за обработку ПДн и отвечать на запросы в течение 10 рабочих дней.
6. При изменении текста согласия менять `ConsentVersion` в `internal/quiz/consent.go`.

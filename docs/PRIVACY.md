# Обработка персональных данных

Документ описывает, какие данные собирает бот, зачем и как долго хранит.
Черновик: юридически значимая редакция должна быть утверждена перед публикацией бота.

## Что собирается

| Данные | Источник | Обязательность |
|---|---|---|
| Telegram ID | автоматически при обращении к боту | технически необходима для ответа |
| Юзернейм (username) | из профиля Telegram | если он публичный |
| Логин в Telegram | пользователь подтверждает сам | только при согласии |
| Время согласия | система | только при согласии |
| Баллы теста и результат | ответы пользователя | только при согласии |
| Число прохождений | система | только при согласии |

## Что не собирается

Телефон, электронная почта, геолокация, содержимое переписки, данные о платежах,
рекламные идентификаторы. Бот не читает сообщения в чатах и группах, куда его
не добавляли явно.

## Зачем

1. **Доставка практики «Переключатель».** Ссылка отправляется в чат; логин нужен,
   чтобы связать запись в базе с человеком.
2. **Рассылка по теме отдыха.** Только от этого бота, только по явно выбранным темам.
   Пользователь не передаётся третьим лицам.

Никакой обработки за пределами этих двух целей нет.

## Основание обработки

Согласие субъекта. Оно запрашивается отдельным сообщением **после** показа результата
теста, с перечислением конкретных данных и целей. Без согласия профиль не создаётся,
в файл не пишется ничего, кроме технического факта обращения.

## Отзыв согласия

Команда `/forget` немедленно удаляет профиль из файла: логин, баллы, время согласия.
Дополнительно можно написать администратору бота с запросом на удаление.

## Хранение и защита

- Файл данных (`DATA_FILE`) вне репозитория: каталог `data/` в `.gitignore`.
- Права на файл `0600`, запись атомарная (временный файл + `rename`).
- Передача в Telegram идёт по TLS — это обеспечивает Bot API.
- В контейнере процесс работает под непривилегированным пользователем (`USER app`).

## Срок хранения

Срок не задан жёстко — данные живут до отзыва согласия. Перед продакшеном
рекомендуется установить период (например, 12 месяцев с последней активности)
и автоудаление по его истечении.

## Права пользователя

| Право | Как реализовано |
|---|---|
| Знать, какие данные собираются | текст согласия перед сбором |
| Отозвать согласие | команда `/forget` |
| Удалить данные | команда `/forget` |
| Возразить против рассылки | `/forget` либо блокировка бота |

## Передача третьим лицам

Не производится. Исключение — инфраструктура Telegram: доставка сообщений
проходит через Bot API, что регулируется правилами самого Telegram.

## Контакт

Перед публикацией укажите здесь адрес для запросов по персональным данным
(например, `privacy@example.com`) и ответственное лицо.
